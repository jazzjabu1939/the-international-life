# Base44 Contractor Audition

## Initial prompt — 2026-08-14

Build one browser-based, first-person 2.5D baggage-claim scene set inside Darwin Airport in the late 1980s. This is an atmospheric travel-exploration experience, not a shooter and not a conventional app dashboard.

The player must be able to pan across a wide airport scene, locate a worn canvas travel bag moving among other luggage on a conveyor, select the correct bag, and receive a clear in-world confirmation that the objective is complete. Selecting an incorrect bag should give subtle feedback and allow another attempt.

Visual direction: beautiful cinematic realism interpreted through an early-2000s exploration-game aesthetic; tropical dusk visible through airport windows; slightly compressed textures; restrained color; quiet uncanniness; first-person viewpoint; minimal HUD containing place, late-1980s date, and the objective "Retrieve your luggage." No visible protagonist face, no weapons, no combat, no enemies, no shooting mechanics.

Requirements:
- Works in an ordinary desktop and mobile browser.
- Mouse-drag or pointer movement pans the scene on desktop; touch-drag pans on mobile.
- Keyboard-accessible alternative for locating and selecting luggage.
- Respect prefers-reduced-motion.
- Include a brief accessible non-animated description of equivalent content.
- Keep this to one complete scene. Do not build the taxi, mall, vendor, Kyoto, login, database, accounts, payments, analytics, or later levels.
- Use no copyrighted game assets, logos, or characters.

Name the prototype "Darwin Arrival — Baggage Claim." Prioritize one working, polished interaction over extra features.

## Evaluation criteria

- Reliable browser load
- Genuine working interaction
- Desktop and touch controls
- Keyboard and reduced-motion support
- Visual quality and atmosphere
- Exportability and integration potential
